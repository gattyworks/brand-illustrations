# Contributing to Brand Illustrations

First off, thank you for considering contributing to the Brand Illustrations Framework! We welcome community contributions, whether it's adding new features, improving the prompt templates, or submitting new dynamic character templates.

## 💬 Discussions & Ideas

Have an idea for a new feature, a cool character template, or a question about how to use the framework?
We encourage you to start a **Discussion** first! 

Head over to the **Discussions** tab on GitHub to share your thoughts, ask questions, and interact with other community members before you start writing code or making major changes.

## 🐛 Raising an Issue

If you spot a bug (like an AI agent misunderstanding a prompt template) or have a specific enhancement request:

1. Check the existing issues to ensure it hasn't already been reported.
2. Open a new **Issue**.
3. Clearly describe the problem or the requested enhancement.
4. If it's a bug, include the prompt you used and the AI output so we can reproduce it.

## 🛠️ Raising a Pull Request (PR)

We love PRs! If you're ready to contribute code or documentation changes:

1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine.
3. **Create a branch** for your feature or bug fix (`git checkout -b feature/my-awesome-idea`).
4. **Make your changes**. If you are adding a new generic character template, place it in the `characters/` folder. Ensure you follow the structure defined in `_template.md`.
5. **Commit your changes** (`git commit -m 'Add some feature'`).
6. **Push to the branch** (`git push origin feature/my-awesome-idea`).
7. **Open a Pull Request** against the `main` branch of our repository.
8. Wait for a maintainer to review your PR. We might suggest some tweaks before merging!

## 🤝 Interaction Guidelines & Code of Conduct

To keep this community welcoming and productive:
- **Be Respectful:** Treat everyone with kindness. Harassment or toxic behavior will not be tolerated.
- **Be Constructive:** When reviewing PRs or discussing issues, provide actionable and polite feedback.
- **Stay on Topic:** Keep issue and PR conversations focused on the framework and its usage.

By contributing to this project, you agree to abide by these guidelines. We are excited to build this alongside you!
