# Examples 🖼️

This directory contains reference images and generated examples demonstrating the Brand Illustrations Framework in action.

## Directory Structure

- **`images/`**: Contains the final rendered images (Square 1:1 format and Banner 16:9 format) generated by the framework. These act as proof-of-concept outputs that you can reference to understand how the AI interprets the character metaphors and brand style.

*Note: You can use these generated examples as inspiration or starting points for your own specific technical illustrations!*
