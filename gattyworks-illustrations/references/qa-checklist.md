# Gattyworks Illustrations QA Checklist

Before finalizing an image generation prompt, the AI must verify the following:

## 1. Concept Clarity
- [ ] Does the visual metaphor accurately represent the technical concept?
- [ ] Is it easy to understand without reading a long explanation?

## 2. Character Usage
- [ ] Are the chosen elemental characters appropriate for the metaphor? (e.g., don't use Terra for something representing speed).
- [ ] Are the character's signature visual traits clearly described in the prompt?

## 3. Format & Composition
- [ ] Is the correct aspect ratio specified (1:1 for square, 16:9 for banner)?
- [ ] For 16:9 banners, is there enough negative space left for typography (e.g., for a YouTube title)?
- [ ] For 1:1 squares, is the action centered with enough padding?

## 4. Brand Style
- [ ] Does the prompt include the required style keywords ("clean, modern vector-style", "Gattyworks brand style", "flat colors")?
- [ ] Are the colors aligned with the character's element and brand guidelines?

## 5. Text Avoidance
- [ ] Does the prompt avoid asking for complex text/sentences that AI image generators often misspell? (If text is needed, it should be added in post-production).
