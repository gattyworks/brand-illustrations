# Brand Identity 🎨

This directory holds the core visual DNA of your brand's illustration style. The AI framework reads these files to ensure that every generated image strictly adheres to your aesthetic guidelines.

## Files

- **[`style-dna.md`](style-dna.md)**: Defines the overall vibe, line art style, color palettes, and core brand elements (e.g., minimalist whiteboard doodles, black outlines, white fills).
- **[`composition-patterns.md`](composition-patterns.md)**: Defines how the canvas is structured, including negative space, layout padding, and typography zones for different image formats (like Square or Banner).

## How to Customize
If you want the framework to generate flat corporate vectors, 3D renders, or pixel art instead of hand-drawn doodles, simply rewrite the contents of `style-dna.md` to perfectly describe your desired art style.
